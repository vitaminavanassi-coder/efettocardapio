# Cardápio Efetto

Cardápio digital mobile-first para clínica, com pedidos via QR Code, painel `/admin` em tempo real e mini estoque simples.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase

## Como rodar

```bash
npm install
npm run dev
```

## Variáveis de ambiente

Copie `.env.example` para `.env.local` e preencha as credenciais do Supabase.
